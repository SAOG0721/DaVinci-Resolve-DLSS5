# Tests

## Build and run

Follow [BUILDING.md](../docs/BUILDING.md) to configure the SDKs and compatible DLSSNR runtime. The build helper runs all nine CTest groups. To rerun an existing script build:

```powershell
ctest --test-dir build -C Release --output-on-failure
```

| Test | Coverage |
| --- | --- |
| Core | Encoding, detail, protection and composition |
| Feature18RuntimeSmoke | Real NGX initialization and processing |
| TimelineRuntimeSmoke | NR history, caching and timeline processing |
| GpuContracts | GPU resources and processing contracts |
| OpticalFlow | AMDOF/NVOF motion direction and quality profiles |
| AntiFlicker | CPU temporal reference and history/reset behavior |
| AntiFlickerGpu | D3D12 temporal processing against the CPU reference |
| OfxHarness | Actual OFX descriptors, parameters, rendering and frame dependencies |
| FusionContracts | Sixteen metadata, input-error, notification and recovery scenarios |

Python test hosts load the actual OFX binary. Runtime tests use the configured DLSSNR DLL. Generated reports and media belong in the ignored `tests/results/` directory.

## Resolve checks

`src/scripts/Verify-ResolveParameters.py` checks native parameter visibility and saved-setting round trips. `tests/Verify-NativeFusion041.py` creates an owned test project for frame-rate, export and recovery checks. Inspect these scripts before running them against Resolve; keep user projects separate from test projects.

For image and interaction checks, compare real footage with Processed, Difference x10 and Output Mix; include sequential playback, seeking, export, SDR/HDR, multiple nodes and external motion. Record Resolve, GPU, driver and runtime versions with the footage encoding, dimensions, pass count and flow settings.

## 0.4.1 verification

Nine CTest groups and sixteen Fusion failure/recovery scenarios passed. Native parameter checks covered 69 controls, ten groups and saved-setting round trips. Resolve checks confirmed frame-rate fallback, export error reporting and recovery after disabling an unconnected external-motion input. Effective NR image changes and real-footage image quality remain for visual acceptance.

Reference environment: Windows x64, Resolve Studio 20.0.1.6, RTX 5070 Ti, NVIDIA driver 616.92, community DLSSNR runtime 310.8.0.0. Test fixtures are generated by this project's scripts; SDKs, runtimes, media, caches and rendered outputs are excluded from Git.
